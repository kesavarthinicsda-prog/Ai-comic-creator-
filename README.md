# ComicCraft - AI Comic Story Creator

ComicCraft is an AI-powered web application that creates
personalized comic stories and illustrations using Gemini AI.

## Features

- Generate AI comic stories
- Create panel-by-panel stories
- Generate character dialogues
- Generate comic illustrations
- Choose story tone
- Choose art style
- Preview comic panels
- Download comic as PDF

## Technologies Used

- Python
- FastAPI
- Google Gemini AI
- HTML
- CSS
- JavaScript
- ReportLab
